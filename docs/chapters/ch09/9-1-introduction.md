# 9.1 引言

没有哪个重要的程序是只用裸露的编程语言写成的。首先会发展出一批库，它们再成为后续工作的基础。大多数程序用裸语言写起来很乏味，而几乎任何任务，只要用上好的库，都能变得简单。

承接第 1–8 章，第 9–18 章对关键的标准库设施做一次快速导览。我非常简略地介绍有用的标准库类型，例如 `string`、`ostream`、`variant`、`vector`、`map`、`path`、`unique_ptr`、`thread`、`regex`、`system_clock`、`time_zone` 和 `complex`，以及使用它们的最常见方式。

与第 1–8 章一样，强烈建议你不要因对细节的理解尚不完整而分心或气馁。本章的目的是传达对最有用库设施的基本理解。

标准库的规范占 ISO C++ 标准的三分之二以上。去探索它，并优先选用它而非自制替代品。其设计倾注了大量思考，实现投入了更多精力，维护与扩展还将持续付出大量努力。

本书描述的标准库设施是每一个完整 C++ 实现的组成部分。除标准库组件外，大多数实现还提供“图形用户界面”系统（GUI）、Web 接口、数据库接口等。类似地，大多数应用开发环境会提供面向企业或工业“标准”开发与/或执行环境的“基础库”。再往外，还有成千上万支持专门应用领域的库。这里，我不描述标准库之外的库、系统或环境。意图是给出一份由标准所定义的、自洽的 C++ 描述 [C++,2020]，并保持示例可移植。自然，鼓励程序员去探索大多数系统上更广泛的可用设施。
